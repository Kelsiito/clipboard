# Project Summary

## Status

`clipboard` is a public, source-first macOS clipboard history app. The v1 implementation is complete, builds with Xcode, and is published under the MIT license. The app is currently unsigned and not notarized.

## User-facing behavior

- The app runs as a menu-bar accessory and does not appear as a normal Dock app.
- `⌘⇧V` opens a compact history picker; the hotkey can be changed in Settings.
- The picker shows three rows, supports scrolling, search-as-you-type, arrow navigation, `Enter`, `Esc`, click-outside dismissal, and a close button.
- `⌘1`–`⌘9` paste the corresponding visible filtered result; item context menus support deletion.
- Items can be pinned, with a maximum of three pinned entries shown first.
- Settings cover the history and GIF hotkeys, optional unset-by-default Clipboard Stack hotkeys, a 10–200 history limit, clearing all or unpinned history, opt-in Launch at Login, and Accessibility status.
- The menu-bar menu exposes `Ignore Next Copy`, which skips one eligible pasteboard snapshot.
- Privacy controls can ignore selected applications, pause capture for 15 minutes, 1 hour, or until resumed, and expire unpinned history after a chosen retention period.
- Clipboard Stack can capture subsequent copies in order and restore them one at a time for sequential paste.
- Clipboard Stack start and paste-next hotkeys are optional, persisted only after the user configures them, and can be cleared from Settings.
- Quick Look is available from each picker row and context menu for text, images, animated GIFs, and existing local file references.
- GIFs can be exported through the menu bar or an individual GIF history row using the native save panel; export does not duplicate history.
- Static images are OCR-indexed asynchronously with Apple's Vision framework; recognized text is persisted locally and participates in search.
- The app UI, repository documentation, developer-facing guidance, and source identifiers are English.

## Storage and privacy

- History is stored locally in `~/Library/Application Support/clipboard/history.json`.
- Text, RTF data, and image payloads are persisted locally.
- Copied files are represented by local bookmarks/references; original files are never copied or deleted by the app.
- Concealed, transient, and autogenerated pasteboard entries are ignored. They do not consume `Ignore Next Copy`.
- Ignored applications and paused capture do not enter history and do not consume `Ignore Next Copy`.
- Retention cleanup preserves pinned items and never deletes original files.
- The stack is session-only and references existing history item IDs rather than duplicating payloads.
- There is no cloud sync, account, backend, analytics, telemetry, or network service.
- Clearing history removes only app-owned history.

## Architecture

- `clipboardApp.swift`: menu-bar scene and app lifecycle.
- `AppState.swift`: settings, global hotkey orchestration, target-app capture, Accessibility status, and paste flow.
- `PasteboardMonitor.swift`: pasteboard polling, source-application filtering, pause state, and transient-content filtering.
- `ClipboardStore.swift`: local persistence, deduplication, history limits, pin ordering, deletion, and retention cleanup.
- `Models.swift`: Codable clipboard, file-reference, hotkey, retention, and pause models.
- `GlobalHotKey.swift`: Carbon global hotkey registration.
- `ClipboardPanelController.swift`: floating picker, placement, animations, keyboard navigation, and rows.
- `QuickLookPreview.swift`: native Quick Look data source with temporary preview copies and cleanup.
- `LocalOCRService.swift`: on-device Vision text recognition for static image history items.
- `SettingsView.swift`: settings UI and Liquid Glass/material compatibility helpers.

## Positioning behavior

When Accessibility is available, the app resolves the target app before activating its own UI and uses the focused standard text role's caret or selection bounds. Coordinates are converted per display before the panel is placed.

If the target app does not expose an editable text element, the app never uses the mouse location. It chooses the largest normal target window and uses a deterministic area fallback. The Codex desktop app exposes its content as a full-window `AXGroup` and has a separate title-bar window; the fallback therefore selects the main window and anchors near its lower composer area.

Without Accessibility, the item is still restored to the system pasteboard. Automatic `⌘V` is skipped and the user can paste manually.

## Validation

The current local validation set is:

```sh
xcodebuild -project clipboard.xcodeproj -scheme clipboard -destination 'platform=macOS' test
xcodebuild -project clipboard.xcodeproj -scheme clipboard -destination 'platform=macOS' build
git diff --check
```

The XCTest suite covers persistence, images, file bookmarks, deduplication, limits, pinning, deletion, clear-unpinned behavior, search, ignore-next-copy behavior, empty and legacy data, hotkey defaults, and panel placement geometry. The GitHub Actions workflow runs the test and build commands on macOS for pushes to `main` and pull requests.

## Manual QA checklist

- Text, image, and multiple-file capture and paste.
- Restart persistence.
- Default and changed history/GIF hotkeys, plus optional Clipboard Stack hotkeys with no defaults.
- Three-row scrolling and pin limit.
- Close button, `Esc`, outside click, and click-to-paste dismissal.
- Menu-bar Settings and Quit actions.
- Settings above other apps.
- Ignored application capture, pause/resume, and retention cleanup with pinned items.
- Clipboard Stack capture, finish/cancel controls, ordered consumption, and manual paste fallback.
- Quick Look from the row eye button and context menu for text, images, GIFs, and files; verify the panel closes and temporary previews are removed.
- Save the latest GIF from the menu bar and an individual GIF from its row; verify `.gif` extension handling, file contents, and no duplicate history item.
- Accessibility granted and denied.
- Standard text-editor caret positioning.
- Window-area fallback for apps that do not expose a caret.

Manual fixtures must be synthetic and must not contain real clipboard history or credentials.
