# Roadmap

## Project Summary

`clipboard` is a local macOS clipboard history app with a Windows+V-style picker, automatic paste, persistent text/image history, and file bookmarks.

## Goals

- Capture useful clipboard content locally.
- Open history with a configurable global hotkey.
- Paste the selected item back into the previously active app.
- Keep UI small, keyboard-friendly, and visible only in the menu bar.

## Non-goals

- Cloud sync, accounts, analytics, backend, App Store delivery, or automatic login launch.
- Copying file bytes into history.

## Target User

Personal macOS user wanting fast clipboard recall.

## Project Type

Desktop app / macOS MVP.

## Platform

macOS 14+.

## Tech Stack

Swift 5 mode, SwiftUI, AppKit, Carbon hotkeys, ApplicationServices Accessibility, local JSON persistence, Xcode.

## Assumptions

- Default hotkey is `⌘⇧V`.
- Default history limit is 50, configurable from 10 to 200.
- Text, images, and file references are one history item when copied together.
- Accessibility is requested only for automatic paste.

## Rules

- No secrets or external services.
- Clear history removes only app-owned data.
- Concealed, transient, and autogenerated pasteboard entries are not stored.
- Validate before commit and push.

## Phase 0 — Setup

- Create Xcode project, tests, docs, MIT license, and app icon asset set.
- Confirm Apple developer tooling.

## Phase 1 — Core MVP

- Add pasteboard polling, filtering, fingerprinting, local persistence, and pruning.

## Phase 2 — Main Features

- Add Carbon global hotkey, picker panel, target-app restoration, and automatic `⌘V`.
- Add image previews and file bookmark restoration.

## Phase 3 — UI/UX Polish

- Add settings, keyboard navigation, Accessibility status, menu-bar behavior, and icon polish.

## Phase 4 — Testing & QA

- Run unit tests, build checks, and manual text/image/file paste scenarios.

## Phase 5 — Deployment / Release

- Build local app, commit, create public GitHub repo, push `main`, verify remote SHA.

## Phase 6 — Post-launch Improvements

- Consider per-item delete, search, launch-at-login, signed builds, and notarization.

## Open Questions

- None blocking v1.

## Risks

- Automatic paste requires Accessibility permission.
- File bookmarks may become stale after a file is moved or deleted.
- Unsigned local builds may trigger macOS trust warnings when shared.

## Definition of Done

- App builds/tests successfully.
- Text, images, and file references persist and paste correctly.
- Hotkey/settings/menu-bar/menu behavior validated.
- Docs updated, commit created, public repo pushed, remote verified.
